# VS Code

## Install

The ai-agent-skills reference guides used to build this documentation do not include a VS Code–specific skill install command.

Install the skill with a compatible installer, for example:

```bash
npx skills add ysskrishna/ysskrishna-mcp
```

Pick VS Code or the host your setup uses when the installer asks.

## Connect the MCP server

After the skill is installed:

Use the MCP server settings UI or **MCP: Add Server**, select HTTP, enter the endpoint `https://www.ysskrishna.space/mcp` and the name `ysskrishna`, and choose the requested configuration destination. Start the server and inspect its tools.
